⚠️ EN CAS DE PROBLÈME
----------------------

ERREUR: "make: command not found"
SOLUTION: sudo apt-get install build-essential

ERREUR: "gcc: command not found"  
SOLUTION: sudo apt-get install gcc

ERREUR: Compilation échoue
SOLUTION: Vérifiez que TOUS les fichiers sont présents
          Relancez: make clean && make
